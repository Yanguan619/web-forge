# 案例与实测数据（证据，不是规则）

> 本文件保存具体站点的实战记录，用来验证/追溯规则，**不参与决策**。
> 规则在 `SKILL.md`，普适片段在 `patterns.md`。站点改版后本文件会自然过时，不必维护。

## 站点形态对照（同一套方法，五种极端形态）

| 形态 | 特征 | 关键做法 |
|---|---|---|
| React + 全套 testid | 每个控件都有稳定 testid | 全走 testid；注意同一 testid 出现在多个状态节点（同名多元素） |
| 纯静态站，0 testid | GitHub Pages 类 | 按 role/标签 + 表单序号定位；纯前端计算 |
| iframe 壳 + hash 路由 | 壳上只有导航，功能在帧里 | 直连内嵌 URL（`?embed=1`）；尾斜杠敏感；选项无 placeholder 时 `options[0]` 即首项 |
| Next.js SSR 榜单 | 0 testid、0 table，全 div 行 | `a[href^="/<实体>/"]` + 叶子 span 类名与顺序；榜首/榜尾字段类型不同要回退 |
| SSR 表格站 | 正表格，但夹着图表占位空表 | 表格提取 + 空壳过滤；语言前缀决定文案 |

## 实测性能与数据（2026-11-03）

- 数据页动作：≈10 分钟固化；带表单（联动下拉/数字输入/双实体对比/8 步向导）30–60 分钟。
- 常驻浏览器复用：同站连续两次运行 5.5s → 2.2s。
- 冒烟全表（7 条动作）：≈70s 串行跑完。
- 典型坑耗时排序（最快踩到→最慢排查）：中文参数乱码 < `goto("/")` 吞路径 < 水合竞态
  < 受控 `<select>` 卡 30s < 跨站共享浏览器导致证书设置污染（29 个残留进程叠加时最费时）。

## 历史迭代要点（每一轮都是真实站点暴露的）

1. **一站一图**：产物从「每 URL 一张流程图」改为「一个站点一张 HTML」。
2. **依赖解析**：捆绑脚本按自身目录 `require` 找不到消费项目的 playwright → 改 CWD `createRequire`。
3. **SPA 水合**：固定 sleep 下选择被水合冲掉 → 等就绪信号 + 重试。
4. **iframe 壳站**：探针加逐帧下钻，否则壳上只能看到导航。
5. **SSR 结构锚点**：无 testid 时用行容器 + 叶子顺序，并准备榜首/榜尾的回退。
6. **参考层拆分**：SKILL.md 保主干，细节下沉（本次再拆为 patterns / cases）。
7. **冷启动测试**：让零上下文的 agent 只凭 manifest 出命令，暴露「manifest 缺合法取值」→
   新增 `--options` 契约。
8. **常驻浏览器**：不关窗、复用标签、断开 CDP 而非 kill；随后发现每站必须独立端口，
   否则 context 设置互相污染。
9. **全量覆盖**：从「用到的才做」改为「路由清单零黑洞 + 覆盖率表」，并加冒烟回归。
10. **证书**：全站 `ignoreHTTPSErrors: true`（用户规则），代价是发现不了中间人。
